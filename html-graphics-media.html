HTML Part 9: Canvas, SVG & Media Streams

HTML Canvas Graphics

The HTML <canvas> element is used to draw graphics on the fly via scripting (usually JavaScript).

HTML SVG Graphics

SVG stands for Scalable Vector Graphics. SVG defines vector-based graphics in XML format. It does not lose quality if it is zoomed or resized
