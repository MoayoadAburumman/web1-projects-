HTML Part 10: HTML5 Browser Web APIs

HTML Geolocation API

The HTML Geolocation API is used to locate a user's geographical position. For privacy reasons, the user must approve the location request.

HTML Drag and Drop API

Drag and drop is a very common feature. It is when you "grab" an object and drag it to a different location sequence layout.

HTML Web Storage API

With web storage, web applications can store data locally within the user's browser securely, and much better than cookies.

HTML Web Workers API

A web worker is a JavaScript running in the background, without affecting the performance of the main interface page.

HTML SSE (Server-Sent Events)

HTML Server-Sent Events allow a web page to get updates from a server automatically (Realtime streaming data data feeds).
