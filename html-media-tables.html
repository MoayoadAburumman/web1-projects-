HTML Part 4: Media & Layouts

HTML Images

Images can improve the design and the appearance of a web page. Syntax: <img src="url" alt="some_text">

HTML Favicon

A favicon is a small image displayed next to the page title in the browser tab. You can use any image you want as your favicon.

<link rel="icon" type="image/x-icon" href="/images/favicon.ico">

HTML Page Title

Every HTML document must have a <title> element inside the <head> block. It defines the title of the document, and is shown in the browser's title bar or page tab.

HTML Tables

HTML tables allow web developers to arrange data into rows and columns using <table>, <tr>, <th>, and <td>.
