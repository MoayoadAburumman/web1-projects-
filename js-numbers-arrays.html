JavaScript Part 4: Arithmetic Data Elements

JS Numbers

JavaScript has only one type of number. Numbers can be written with, or without, decimals (e.g., 34.00 or 34).

JS Number Methods

Number methods help you work with numbers. Key methods include toString(), toExponential(), and toFixed().

JS Arrays

An array is a special variable, which can hold more than one value at a time. Array indexes start with 0.

JS Array Methods

Array methods like push(), pop(), shift(), and join() make it easy to manipulate arrays.

JS Array Sorting Engines

The sort() method sorts an array alphabetically. For numbers, you need to use a custom compare function.
