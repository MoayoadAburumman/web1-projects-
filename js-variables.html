JavaScript Part 2: Variables & Operations

JS Variables

Variables are containers for storing data values. In older scripts, we used var, but modern standards prefer cleaner tracking keywords.

Math result container...

JS Let & Const

The let keyword allows you to declare variables that are limited to the scope of a block. The const keyword allows you to declare values that cannot be reassigned later.

JS Operators

JavaScript operators are used to assign values, compare values, and perform arithmetic operations. Assignment operator: =, Addition operator: +.

JS Arithmetic Engines

Arithmetic operations are performed on numbers (literals or variables). Standard operators are addition +, subtraction -, multiplication *, and division /.

JS Data Types

JavaScript variables can hold many data types: Numbers, Strings, Objects, Booleans, Arrays, and more. JavaScript evaluates expressions from left to right dynamically.
