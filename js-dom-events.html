JavaScript Part 12: DOM Styles & Event Handling

DOM HTML & Changing CSS Styles

The HTML DOM allows JavaScript to change the style of an HTML element dynamically using the syntax: element.style.property = new style.

Watch my styling change!

DOM Events

An HTML DOM event can be executed when something happens, like clicking a button, hovering over a division element, or submitting forms.

DOM EventListeners

The addEventListener() method attaches an event handler to the specified element without overwriting existing event handlers. You can add many event handlers to one element.
