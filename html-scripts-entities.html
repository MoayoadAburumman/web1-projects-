HTML Entities

Some characters are reserved in HTML (like the less than sign). Reserved characters must be replaced with character entities to render properly on screens.

To display a less-than sign, we use: &lt; which renders as: <

Non-breaking space entity: &nbsp;

HTML Symbols

HTML entities can display mathematical symbols, currency symbols, and arrows that are not present on a normal standard hardware keyboard.

&euro; displays as: €

&alpha; displays as: α

HTML Emojis

Emojis are characters from the UTF-8 alphabet character set. To display an emoji, your HTML page must declare meta charset UTF-8.

Code &#128514; displays as: 😂

HTML URL Encode

URLs can only be sent over the Internet using the ASCII character-set. URL encoding converts non-ASCII characters into a format that can be transmitted securely.
