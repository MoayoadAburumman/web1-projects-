CSS Part 2: Backgrounds & Box Model

CSS Backgrounds

The CSS background properties are used to add background effects for elements. Properties include: background-color, background-image, background-repeat, and background-position.

Box with customized background color and dashed borders.

CSS Borders

The CSS border properties allow you to specify the style, width, and color of an element's border. You can also round the corners using border-radius.

This paragraph has a thick solid blue border with rounded corners.

CSS Margins

The CSS margin properties are used to create space around elements, outside of any defined borders. You have full control over the margin-top, margin-right, margin-bottom, and margin-left.

This box has a 30px external margin separating it from surrounding wrappers.

CSS Padding

The CSS padding properties are used to generate space around an element's content, inside of any defined borders. Padding clears an area around the content inside an element.

This box has 25px internal padding pushing the text away from its own border.

CSS Height, Width & Box Model

The height and width properties are used to set the height and width of an element. The total width of an element is calculated as: width + left padding + right padding + left border + right border + left margin + right margin.
