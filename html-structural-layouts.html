HTML Part 5: Block, Inline & Structural Layout

HTML Block and Inline Elements

Every HTML element has a default display value depending on what type of element it is. Block-level elements always start on a new line. Inline elements do not start on a new line.

HTML Div Element

The <div> element is a block-level container used to group other HTML elements together and style them with CSS.

HTML Classes

The HTML class attribute is used to specify a class for an HTML element. Multiple elements can share the same class name to inherit the same styles.

HTML Id Attribute

The HTML id attribute is used to specify a unique id for an HTML element. An id value must be completely unique within the page document.
